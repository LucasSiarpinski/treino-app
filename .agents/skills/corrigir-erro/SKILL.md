# Corrigir erro
1. Leia a mensagem de erro inteira. Se faltar informação, peça o log completo.
2. Explique em linguagem simples o que o erro significa.
3. Liste até 3 causas prováveis, da mais para a menos provável.
4. Proponha a menor correção possível para a causa mais provável. Não refatore outras partes.
5. Aguarde aprovação antes de alterar arquivos.
6. Depois de corrigir, diga como confirmar no iPhone que o erro sumiu.
7. Se a correção não funcionar após 2 tentativas, PARE e sugira voltar ao último commit.
